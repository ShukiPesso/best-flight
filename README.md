# סורק דילים לטיסות ישירות מישראל

מערכת שרצה כל יום, מחפשת טיסות **ישירות** הלוך-חזור מנתב"ג ומרמון ליעדים שבחרתם,
מסננת שבתות וחגים, ומציגה בדף אינטרנט את הדיל הזול ביותר לכל יעד.
אין בה שימוש ב-LLM בזמן ריצה. היא עובדת רק מול APIs:

| API | תפקיד | עלות |
|---|---|---|
| [Hebcal](https://www.hebcal.com/home/developer-apis) | זמני הדלקת נרות והבדלה לכל שדה תעופה, כולל יום טוב שני בחו"ל | חינם |
| [SerpApi – Google Flights](https://serpapi.com/google-flights-api) | חיפוש טיסות, ואימות שהמוכר הוא חברת התעופה עצמה | 250 חיפושים בחודש חינם, תוכניות בתשלום |
| [Duffel](https://duffel.com) | הצעות שמגיעות ישירות מחברות התעופה, כולל כבודה | כ-0.005$ לחיפוש |
| [Frankfurter](https://frankfurter.dev) | המרת מטבע לשקלים (ל-Duffel) | חינם |

## איך זה עובד
1. **תכנון:** לכל יעד ולכל תאריך ב-90 הימים הקרובים נבנית רשימה של חיפושי "הלוך" ו"חזור" חד-כיווניים.
   תאריכים שבהם אי אפשר להמריא בכלל (שבת או חג מלאים) לא נחפשים.
2. **תקציב:** בכל ריצה מתבצעים חיפושים רק עד התקציב שב-`config.yaml`. קודם נחפשים התאריכים שלא נבדקו הכי הרבה זמן,
   וקרובים מתרעננים לעיתים קרובות יותר. ימים ומסלולים שבהם אף פעם אין טיסה ישירה נבדקים לעיתים רחוקות יותר.
3. **סינון שבת/חג** (`flightscan/shabbat.py`):
   * הנחיתה ביעד, או בארץ בחזור, חייבת להיות לפחות 3 שעות לפני הדלקת נרות.
   * ההמראה במוצאי שבת/חג רק 3.5 שעות אחרי הבדלה או יותר.
   * בחו"ל נחסם גם יום טוב שני של גלויות. כל הערכים ניתנים לשינוי.
4. **שילוב:** כל הלוך מתאים משודך לכל חזור מתאים, 4–8 ימים. הצעות של 3 ימים או של 9–10 ימים מוצגות רק אם הן זולות ב-15% לפחות.
5. **אימות מחיר חברת תעופה:** Google Flights מציג לפעמים מחיר של סוכן. לטיולים הזולים ביותר המערכת בודקת
   מי מוכר את הכרטיס ושומרת רק את המחיר של חברת התעופה עצמה, יחד עם שם התעריף והכבודה.
   הצעה שאין לה מוכר שהוא חברת תעופה נפסלת. הצעה שעוד לא אומתה מסומנת "טרם אומת".
6. **פלט:** `docs/deals.json`, שאותו מציג `docs/index.html`.

## הגדרה ב-GitHub (ריצה יומית ודף אינטרנט)
1. יוצרים ריפו חדש ב-GitHub ומעלים אליו את התיקייה.
2. **Settings → Secrets and variables → Actions:** מוסיפים `SERPAPI_KEY` ו/או `DUFFEL_TOKEN`.
3. **Settings → Pages:** בוחרים Deploy from branch, את הענף `main` ואת התיקייה `/docs`.
4. **Actions → Daily flight scan → Run workflow** מריץ את הסריקה הראשונה. משם היא רצה כל בוקר.

> GitHub Pages בחינם עובד רק בריפו ציבורי. הדף לא מכיל שום מידע אישי, והמפתחות נשמרים כ-Secrets ולא נחשפים.

## הרצה מקומית
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m flightscan.scan --demo      # נתוני הדגמה, בלי מפתחות
SERPAPI_KEY=... .venv/bin/python -m flightscan.scan
python3 -m http.server -d docs 8000             # ואז http://localhost:8000
```

## הוספת יעד
מוסיפים את קוד השדה ל-`destinations` ב-`config.yaml`. אם השדה לא מופיע ב-`flightscan/airports.py`,
מוסיפים שם שורה עם עיר, מדינה, קו רוחב, קו אורך ואזור זמן.

## כמה חיפושים צריך?
כל יעד דורש בערך 180 חיפושים לסבב מלא (90 ימי הלוך ועוד כ-95 ימי חזור, פחות שבתות וחגים).
8 יעדים הם בערך 1,500 חיפושים לסבב מלא.
* **SerpApi בחינם** (כ-8 ביום): מתאים רק לניסיון. סבב מלא ייקח חודשים.
* **SerpApi Developer** (5,000 בחודש, כ-160 ביום): התאריכים הקרובים מתרעננים כל יום או יומיים, והרחוקים בערך פעם בשבוע.
* **Duffel**: כ-0.005$ לחיפוש. סבב מלא יומי לשני שדות מוצא עולה בערך 15$ ליום, ולכן כדאי להגביל את התקציב.

שנו את `daily_search_budget` לפי התוכנית שלכם.
